## 安装和兼容

导入 `payload/pokemon.js`，然后在 SeaDice WebUI 重载 JS 扩展。已有旧版时应原位替换，避免同时启用多份。`install_update.ps1` 是面向已有旧版的 Windows 更新脚本；它校验哈希、备份旧 JS、只替换 JS，不升级或重启核心。

原生旅伴卡功能需要 `seal.character.getCurrent` / `patchCurrent` 等艾拉自编译核心接口，标准核心不一定支持。仓库不附带私人核心；请勿把此 JS 更新理解为给任意标准核心安装完整规则。

## 常用操作

1. `.set pkm` 切换规则，`.pc new 角色名` 创建并绑定旅伴卡。
2. 用 `.pst` 录入属性，或配合一键录卡导入表格中的训练家和伙伴队伍。
3. `.pm 技能名` 检定，`.宝可梦队伍` 查看当前卡的队伍。
4. `.宝可梦伤害 <伙伴> <目标属性> <招式>` 生成命中与伤害结果；实际参数见插件内帮助。
5. `.sn pkm` / `.sn 旅伴` 设置名片，`.th` 查看相关信息。

原有玩家存储命名空间保留。切换绑定的角色卡后，检定与队伍随之切换；旧档迁移由 `.宝可梦迁移` 显式执行。
