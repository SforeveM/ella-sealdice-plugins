# 拆炸弹 v1.0.0

这是一个 SeaDice 图文按钮小游戏。每局有红、蓝、黄、绿、紫、白六根线，其中固定一根是随机错误线路。

## 玩法

- 第一根安全线的可结算奖励是 40 宝可元。
- 连续安全剪线后的当前奖励依次为：40、80、160、320、640。
- 奖励不会在剪线时立即到账，必须选择“立即收手”才结算。
- 剪中错误线路时，本局未结算奖励归零，并从玩家账户额外扣除当前累计奖励数目。
- 爆炸扣款允许宝可元余额变成负数。
- 六根线中只有五根安全线；剪完五根安全线后，剩余的一根必然是错误线路。
- 每名玩家默认每天只能开始一局；未结束的局不会因为跨消息而消失。

例如：已经安全剪过三根线时，当前奖励是 160。此时收手会获得 160；继续剪中错误线，则不会获得这 160，并且账户还会额外扣除 160。

## 经济限制

错误线在六种颜色中均匀随机。若玩家事先决定连续安全剪到固定数量再收手，理论期望值如下：

- 1 根后收手：约 +33.33 宝可元
- 2 根后收手：约 +46.67 宝可元
- 3 根后收手：约 +60 宝可元
- 4 根后收手：约 +60 宝可元
- 5 根后收手：约 +6.67 宝可元

因此玩法本身是正期望。默认每日一局用于限制货币增发；可在海豹扩展配置中修改“每日可开始局数”，但不建议提高。

## 宝可元兼容

插件直接读写宝可梦钓鱼插件的主账户：

- 扩展：`fishingSystemV2`
- 存档后缀：`_pokemon_fish_v1`
- 余额字段：`coins`

不创建第二套货币，不修改钓鱼插件接口。每次结算都有独立交易 ID，重复点击旧按钮不会重复发钱或扣钱。

## 指令

- `.拆弹`：打开主菜单。
- `.拆弹 开始`：开始今日拆弹。
- `.拆弹 状态`：查看或刷新当前局。
- `.拆弹 规则`：查看规则。
- `.拆弹 剪 红`：不用按钮时手动剪红线；也支持蓝、黄、绿、紫、白。
- `.拆弹 收手`：立即结算当前奖励。
- `.拆弹 测试重置`：仅骰主可用，清除自己的今日次数和当前测试局，不修改宝可元。
- `.拆炸弹`、`.bomb`：与 `.拆弹` 相同。

## 安装

管理员 PowerShell：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install_update.ps1 -CoreRoot "C:\SeaDice"
```

如果不希望重启海豹核心：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install_update.ps1 -CoreRoot "C:\SeaDice" -SkipRestart
```

不重启安装后，需要在海豹 WebUI 的扩展页面手动执行一次“重载 JS”。图片后端仍会正常启动，并注册开机自启动任务。
